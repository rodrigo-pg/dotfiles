Neovim keyboard shortcuts

A quick guide to navigating, editing, and coding without leaving the keyboard.

Leader = Space. Press, release, then type the letters in sequence.
Shortcuts use normal mode unless noted. Press Esc to return to it.

Saving and quitting

:w EnterSave file
:wq EnterSave and close window
:q! EnterClose without saving changes to the current buffer
Space qqQuit all windows; warns about unsaved changes

Type colon commands in normal mode and confirm with Enter.

No need to memorize everything: press Space and wait for the shortcut menu. Shortcuts are case-sensitive. Some combinations may be intercepted by your terminal. This guide works offline.
